## 克隆仓库

```sh
git clone https://github.com/TheOninesixY/Termin.git
```

## Run it !

```sh
cd Termin
python3 termin.py
```

## 添加.desktop文件到应用程序菜单

```sh
cp io.github.theoninesixy.Termin.desktop $HOME/.local/share/applications/
cp icon.svg $HOME/.local/share/icons/hicolor/scalable/apps/io.github.theoninesixy.Termin.svg
```
